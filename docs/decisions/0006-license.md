# 0006: Apache-2.0 licence

**Status:** Accepted (2026-11-25). Revisit before accepting outside contributions.

## Context
The project is meant to be a free alternative that anyone, including public agencies, can
use.

## Decision
Apache License 2.0: permissive, includes a patent grant, standard in the Rust ecosystem,
and acceptable to most organisations' legal teams.

## Alternative
AGPL-3.0 would force anyone who builds a product on this code to publish their changes,
but some organisations forbid AGPL software. Switching is easy while the owner and Claude
are the only contributors and hard afterwards.
